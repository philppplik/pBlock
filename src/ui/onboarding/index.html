pBlock ist einsatzbereit.

Ab sofort werden Werbung, Tracker und bekannte Schadsoftware-Domains blockiert. Drei kurze Fragen, dann passt die Einstellung zu deinem Surfverhalten.

  • Keine Datensammlung. Alles läuft auf deinem Gerät. Es wird nichts übertragen, nichts gespeichert, nichts ausgewertet.
  • Quelloffen. Der gesamte Code liegt öffentlich auf GitHub und kann geprüft werden.
  • Umkehrbar. Jede Einstellung lässt sich jederzeit ändern oder zurücksetzen.

Wie streng soll gefiltert werden?

Mehr Schutz bedeutet auch ein höheres Risiko, dass einzelne Seiten anders aussehen als gewohnt. Du kannst das jederzeit anpassen.

Schutzstufe

Zwei Dinge, die gut zu wissen sind.

Eine Seite funktioniert nicht?

Klicke auf das pBlock-Symbol und schalte den Regler neben der Adresse um. Die Seite wird dann vom Blockieren ausgenommen und neu geladen.

Tastenkürzel: Alt + Umschalt + P

Etwas Störendes entdeckt?

Rechtsklick auf das Element und „Element auf dieser Seite blockieren“ wählen. pBlock blendet es dauerhaft aus — auch beim nächsten Besuch.

Tastenkürzel: Alt + Umschalt + E
