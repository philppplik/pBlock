DIREKTE ANTWORTEN

Gut zu wissen.

Was ist pBlock?

pBlock ist eine MIT-lizenzierte Chrome-Erweiterung, die Werbung, Tracker und bekannte Schadsoftware-Domains blockiert.

Wie installiere ich pBlock?

Im Chrome Web Store oder aus dem Quellcode: Node.js 20+, npm install, npm run build. Dann dist/ als entpackte Erweiterung laden. Die Store-Version kann hinter GitHub liegen.

Wird mein Surfverhalten übertragen?

pBlock hat keinen eigenen Server und keine Telemetrie. Optionale Filterlisten werden von ihren Anbietern geladen. Lokale Statistik kann in den Einstellungen gelöscht werden.

Kann eine Website dadurch kaputtgehen?

Ja. Strengere Kategorien können Funktionen einer Seite blockieren. Nimm die Seite aus oder reduziere die Schutzstufe.
