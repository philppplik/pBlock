Was pBlock kann

Drei Stufen statt hundert Schalter

Ein Regler von „Minimal“ bis „Maximum“ regelt alles. Wer es genauer will, schaltet in den Expertenmodus und steuert jede Filterkategorie und Unterkategorie einzeln.

  • Werbung
  • Tracker
  • Social Media
  • Störendes
  • Schadsoftware
  • Hersteller-Telemetrie

Element-Picker

Etwas stört, das kein Filter erfasst? Rechtsklick, anklicken, weg — dauerhaft, auch beim nächsten Besuch. pBlock zeigt vorher, wie viele Elemente betroffen wären.

Filterlisten

EasyList, EasyPrivacy, EasyList Germany, Peter Lowe und URLhaus lassen sich zuschalten. Sie werden heruntergeladen und lokal in Regeln übersetzt.

Ausnahmen pro Seite

Eine Seite funktioniert nicht? Ein Klick im Popup nimmt sie aus — inklusive aller Subdomains, ohne den Schutz überall abzuschalten.

Diagnose eingebaut

Ein Selbsttest prüft Regeln, Speicher und Filterlisten. Der Bericht lässt sich herunterladen und einer Fehlermeldung beilegen — ohne persönliche Daten.

Statistik, die bleibt wo sie ist

Blockierte Anfragen, Verlauf und Verteilung nach Kategorie. Gespeichert ausschließlich lokal, jederzeit löschbar.

Was pBlock nicht tut

  • Keine Analyse. Es gibt keinen Analyse-Dienst, keine Kennung und keinen Zähler — weder in der Erweiterung noch auf dieser Seite.
  • Kein Verlauf. Besuchte Adressen werden weder gespeichert noch übertragen. Die Statistik zählt Treffer, nicht Seitenaufrufe.
  • Kein „akzeptable Werbung“. Es gibt keine Liste bezahlter Ausnahmen. Was du blockierst, bleibt blockiert.
  • Kein nachgeladener Code. Filterlisten sind Textdateien. Sie werden gelesen, nicht ausgeführt.

Nachprüfbar: Der vollständige Quellcode liegt offen, und die Berechtigungen im Manifest sind auf das Nötigste beschränkt. Details in der Datenschutzerklärung.

Installieren

Aus dem Chrome Web Store

Die bequemste Variante mit automatischen Updates.

Im Web Store öffnen

Die dort veröffentlichte Fassung kann hinter dem Stand auf GitHub liegen, solange die Prüfung durch Google läuft.

Aus dem Quellcode

Voraussetzung: Node.js 20 oder neuer.

git clone https://github.com/philppplik/pBlock.git
cd pBlock
npm install
npm run build

Anschließend chrome://extensions öffnen, den Entwicklermodus einschalten, „Entpackte Erweiterung laden“ wählen und den Ordner dist/ auswählen.

Etwas funktioniert nicht?

Fehlerberichte sind willkommen — besonders mit dem Diagnosebericht aus den Einstellungen. Er enthält Regelzahlen und Protokolleinträge, aber keine besuchten Adressen.
